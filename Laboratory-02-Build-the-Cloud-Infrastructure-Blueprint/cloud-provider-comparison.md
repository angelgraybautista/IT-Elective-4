# Cloud Provider Comparison

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Compute | Amazon EC2 | Azure Virtual Machines | Google Compute Engine |
| Storage | Amazon S3 | Azure Blob Storage | Google Cloud Storage |
| Networking | Amazon VPC | Azure Virtual Network | Google Cloud VPC |
| IAM | AWS IAM | Microsoft Entra ID | Google Cloud IAM |

## Guide Questions

### 1. Which cloud provider offers the broadest range of services?

I think AWS offers the broadest range of cloud services. It has many services for computing, storage, networking, databases, security, and other cloud needs.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products?

I would recommend Microsoft Azure because it works well with Microsoft products. It can easily work with services such as Windows Server and Microsoft 365.

### 3. Which platform is widely recognized for AI, ML, and Kubernetes services?

Google Cloud is well known for AI, machine learning, and Kubernetes services. It also provides Google Kubernetes Engine for running applications using containers.

### 4. What similarities did you observe among the three cloud providers?

All three providers offer similar basic cloud services. They all have computing, storage, networking, and identity management services.
