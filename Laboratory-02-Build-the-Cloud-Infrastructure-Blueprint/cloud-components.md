# Cloud Infrastructure Components

## 1. Compute Resources

**Purpose:**  
Compute resources provide the processing power needed to run applications and services.

**Importance in Cloud Computing:**  
They allow cloud applications and workloads to run and can be adjusted depending on resource requirements.

**KillerCoda Environment:**  
The server uses an **Intel Xeon E312xx (Sandy Bridge, IBRS update)** CPU with **1 CPU core** and **1.9 GiB RAM**.

---

## 2. Storage Resources

**Purpose:**  
Storage resources provide space for the operating system, applications, and files.

**Importance in Cloud Computing:**  
Cloud systems need storage to save and access data and system files.

**KillerCoda Environment:**  
The server has a **19 GB `/dev/vda1` disk** mounted at `/`. Other mounted storage includes `/boot` and `/boot/efi`.

---

## 3. Networking Resources

**Purpose:**  
Networking resources allow servers and applications to communicate with other systems.

**Importance in Cloud Computing:**  
Networking provides connectivity between cloud servers, applications, and users.

**KillerCoda Environment:**  
The server hostname is **ubuntu** and its IP addresses are **172.30.1.2** and **172.17.0.1**.

---

## 4. Operating System

**Purpose:**  
The operating system manages hardware resources and provides the environment for applications and services.

**Importance in Cloud Computing:**  
It provides the basic platform needed to run and manage cloud applications and services.

**KillerCoda Environment:**  
The server runs **Ubuntu 24.04.4 LTS** with kernel version **6.8.0-136-generic**.
