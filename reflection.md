# Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

I think compute is the most important component because it runs applications and services. Without compute resources, the other cloud resources would not be very useful.

## 2. How does Linux support cloud computing?

Linux provides a reliable operating system for cloud servers. It also has many tools and commands that can be used to manage and monitor servers.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation helps organize the information about the infrastructure. It also makes it easier for other people to understand the setup and avoid mistakes.

## 4. What new skills did you learn during this laboratory activity?

I learned how to use KillerCoda and Linux commands to check server information. I also learned how to document cloud infrastructure using Markdown and organize files in GitHub.

## 5. How has your GitHub portfolio improved after completing this mission?

My GitHub portfolio is more organized because I added different Markdown files, a cloud infrastructure diagram, and screenshots. It also shows the work I completed during the laboratory activity.
