# Microsoft Azure Research

## Brief Overview
Microsoft Azure is Microsoft's public cloud platform. It provides computing, storage, networking, databases, identity, analytics, AI, and developer services for applications and enterprise workloads.

## Global Infrastructure
Azure provides a global infrastructure organized into regions and geographies. Microsoft's product availability documentation currently lists more than 70 announced regions, allowing organizations to select locations appropriate for customers, performance, and regulatory requirements.

## Cloud Management Console
The Azure portal is a web-based unified console for managing Azure subscriptions and resources. It can be used to build, manage, monitor, and organize cloud deployments.

## Four Core Services

| Category | Azure Service | Purpose |
|---|---|---|
| Compute | Azure Virtual Machines | Runs Windows or Linux virtual machines |
| Storage | Azure Blob Storage | Provides object storage for unstructured data |
| Networking | Azure Virtual Network | Provides private networking for Azure resources |
| Identity | Microsoft Entra ID | Provides identity and access management |

## Three Advantages
1. **Strong Microsoft integration:** Azure works closely with Microsoft technologies and enterprise products.
2. **Enterprise capabilities:** Azure provides services for governance, security, identity, and hybrid environments.
3. **Global infrastructure:** Azure offers a broad geographic footprint with many announced regions.

## Typical Enterprise Use Cases
- Windows Server workloads
- Microsoft 365 and identity integration
- Hybrid cloud environments
- Enterprise application hosting
- Data and analytics
- AI and machine learning
