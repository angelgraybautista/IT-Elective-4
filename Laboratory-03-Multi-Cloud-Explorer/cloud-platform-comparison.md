## Questions

### 1. Which cloud provider offers the broadest range of services?
AWS is generally recognized for having one of the broadest cloud service portfolios. Its large catalog allows organizations to build many different types of workloads using services from the same provider.

### 2. Which provider best integrates with Microsoft technologies?
Microsoft Azure is the strongest choice for organizations already using Microsoft technologies. Its services are designed to integrate closely with products such as Windows Server, Microsoft 365, and Microsoft Entra ID.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?
Google Cloud is a strong choice for AI/ML and Kubernetes because of Google's experience in large-scale data systems and container orchestration. Google Kubernetes Engine provides managed Kubernetes capabilities, while Google Cloud also offers a broad AI and data ecosystem.

### 4. Which cloud platform would you personally choose and why?
**Personal choice: Microsoft Azure.** I would choose Azure because it provides strong enterprise services and integrates well with Microsoft technologies. For an organization already using Windows Server, Microsoft 365, and Active Directory, this integration can make cloud migration easier to manage.

## Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| Startup Company | AWS | Broad services and scalable infrastructure give a startup many options as it grows. |
| Enterprise Organization | Azure | Strong enterprise management, security, identity, and hybrid capabilities. |
| Microsoft Environment | Azure | Best fit for Windows Server, Microsoft 365, and Microsoft identity technologies. |
| AI / Machine Learning | GCP | Strong AI/ML and data capabilities make it a suitable choice for research workloads. |
| Kubernetes Deployment | GCP | GKE is a mature managed Kubernetes service based on Google's large-scale Kubernetes experience. |
| Global Web Application | AWS | Broad global infrastructure and multiple Availability Zones support highly available applications. |
