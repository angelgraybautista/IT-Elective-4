# Mission Reflection

This mission helped me understand the differences between AWS, Microsoft Azure, and Google Cloud Platform. The cloud platform that impressed me the most was **Microsoft Azure** because it has strong integration with Microsoft technologies and provides many services that can be useful for organizations and businesses. I also learned that each cloud provider has different strengths, so choosing a cloud platform should depend on what the organization actually needs.

AWS, Azure, and GCP have many similarities. All three provide important cloud services such as virtual machines, object storage, networking, identity management, databases, and Kubernetes. They also allow users to scale resources depending on their workload and provide cloud infrastructure that can be accessed through web-based management consoles.

Business requirements are very important when selecting a cloud provider. For example, a company that already uses Windows Server, Microsoft 365, and Active Directory may benefit more from Azure because of its Microsoft integration. On the other hand, a company focused on Artificial Intelligence and Machine Learning may prefer Google Cloud because of its strong AI and data services. A startup may prioritize scalability and available services while keeping its costs manageable.

Acting as a Cloud Solutions Consultant taught me that there is no single cloud provider that is perfect for every organization. I learned that I should first understand the client's requirements and then compare the available services before making a recommendation. This mission also helped me think more about how cloud technologies can solve real business problems.

My GitHub Cloud Computing Portfolio improved because I added more organized documentation, research, comparison tables, recommendations, and screenshots. I also gained more experience using Markdown and organizing my work in a GitHub repository. Overall, this mission improved my understanding of multi-cloud environments and helped me become more confident in evaluating cloud solutions.
