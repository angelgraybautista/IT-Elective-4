# AWS Research

## Brief Overview
Amazon Web Services (AWS) is a public cloud platform that provides on-demand computing, storage, networking, databases, security, analytics, and many other services. AWS is designed for organizations ranging from startups to large enterprises.

## Global Infrastructure
AWS organizes its infrastructure into geographic Regions and Availability Zones. Availability Zones are isolated locations within Regions and are connected using low-latency, high-bandwidth networking. AWS documentation states that each Region has multiple Availability Zones and recommends multi-AZ designs for higher availability.

## Cloud Management Console
The AWS Management Console is a web-based interface used to access and manage AWS services. It provides a unified interface for discovering services, accessing recently used services, and managing cloud resources.

## Four Core Services

| Category | AWS Service | Purpose |
|---|---|---|
| Compute | Amazon EC2 | Runs virtual servers in the cloud |
| Storage | Amazon S3 | Provides scalable object storage |
| Networking | Amazon VPC | Creates isolated virtual networks |
| Identity | AWS IAM | Controls identities, roles, and permissions |

## Three Advantages
1. **Broad service selection:** AWS provides a very large collection of cloud services.
2. **Global reach:** AWS has Regions and Availability Zones across many geographic areas.
3. **Scalability:** AWS services can support workloads that grow from small applications to large enterprise systems.

## Typical Enterprise Use Cases
- Web and mobile application hosting
- Backup and disaster recovery
- Enterprise databases
- Data analytics
- Content delivery
- Machine learning workloads
