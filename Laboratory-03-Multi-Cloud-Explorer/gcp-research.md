# Google Cloud Platform Research

## Brief Overview
Google Cloud Platform (GCP), commonly called Google Cloud, is Google's public cloud platform. It provides computing, storage, networking, databases, analytics, AI/ML, and container services.

## Global Infrastructure
Google Cloud organizes infrastructure into regions and zones and supports regional and multi-region deployments. Google Cloud documentation lists products such as Compute Engine, Google Kubernetes Engine, Cloud Storage, Cloud SQL, and Virtual Private Cloud as core services available across regions.

## Cloud Management Console
The Google Cloud console is the web interface for managing Google Cloud projects, resources, services, IAM, billing, and other cloud configurations.

## Four Core Services

| Category | GCP Service | Purpose |
|---|---|---|
| Compute | Compute Engine | Runs configurable virtual machines |
| Storage | Cloud Storage | Provides scalable object storage |
| Networking | Virtual Private Cloud (VPC) | Provides cloud networking |
| Identity | Cloud IAM | Controls access to Google Cloud resources |

## Three Advantages
1. **Strong AI/ML ecosystem:** Google Cloud provides extensive AI and machine-learning capabilities.
2. **Kubernetes expertise:** Google Kubernetes Engine (GKE) is a managed Kubernetes platform based on Google's experience operating large-scale container workloads.
3. **Data and analytics:** Google Cloud provides strong services for data processing, analytics, and machine learning.

## Typical Enterprise Use Cases
- AI and machine learning
- Kubernetes and containerized applications
- Big-data analytics
- Web applications
- Data platforms
- Global services
